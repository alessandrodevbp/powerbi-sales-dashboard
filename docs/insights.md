# 🔎 Insights do Dashboard

## 1. Faturamento ao longo do tempo

O dashboard permite acompanhar a evolução do faturamento nos períodos disponíveis no dataset.

Uma análise mais completa deve relacionar eventuais aumentos ou reduções com os segmentos, países e produtos responsáveis pelas variações observadas.

## 2. Faturamento por segmento

Os segmentos apresentam diferentes níveis de faturamento.

O próximo passo analítico é cruzar faturamento com lucro e margem para verificar se os segmentos de maior receita também apresentam maior rentabilidade.

## 3. Faturamento por país

O dashboard permite identificar os mercados com maior e menor faturamento.

Um país com menor faturamento não deve ser considerado automaticamente como um problema. É necessário investigar volume de vendas, lucro, margem e contexto comercial antes de propor uma ação.

## 4. Faturamento por produto

O gráfico atual apresenta faturamento por produto.

Portanto, ele não deve ser interpretado diretamente como ranking de produtos mais vendidos em unidades.

Para uma análise de demanda mais completa, deve-se comparar `Units Sold` com faturamento e lucro.

## 5. Possíveis análises futuras

Com dados adicionais, seria possível investigar:

- estoque parado;
- excesso de estoque;
- quantidade comprada versus quantidade vendida;
- margem por produto;
- crescimento por período;
- participação de cada produto no faturamento;
- rentabilidade por país e segmento.
